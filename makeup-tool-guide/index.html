🖌️ 化妆刷系列

专业化妆刷的使用技巧与保养方法

粉底刷

用于涂抹粉底液、粉底霜等底妆产品，打造均匀服帖的底妆效果。

✨ 采用点压或打圈方式上妆
✨ 从面部中央向外推开
✨ 少量多次，避免厚重感
✨ 每周清洗1-2次
✨ 使用专用刷具清洁剂
✨ 平放晾干，避免暴晒

散粉刷

用于定妆，沾取散粉或蜜粉均匀扫于面部，固定妆容。

✨ 轻轻抖掉多余粉末
✨ 以打圈方式轻扫
✨ T区可重点定妆
✨ 每周清洗一次
✨ 用温和洗发水清洗
✨ 自然悬挂晾干

眼影刷

用于涂抹眼影，打造层次感眼妆，包括晕染刷、细节刷等。

✨ 浅色大面积打底
✨ 深色加深眼尾和眼窝
✨ 干净刷子晕染边界
✨ 每次使用后用纸巾擦拭
✨ 每周深度清洁
✨ 避免刷毛变形

🥚 美妆蛋系列

美妆蛋的正确使用与清洁方法

水滴美妆蛋

最常用的美妆蛋形状，适用于全脸上妆，尖端处理细节部位。

✨ 使用前充分浸湿挤干
✨ 采用点压拍打方式
✨ 尖端处理眼角鼻翼
✨ 每次使用后立即清洗
✨ 用专用清洁剂或肥皂
✨ 放置通风处晾干

斜切美妆蛋

斜切面设计，更适合打造轮廓和修容，平面贴合面部曲线。

✨ 斜切面用于脸颊额头
✨ 边缘打造修容轮廓
✨ 可干湿两用
✨ 定期更换建议1-3个月
✨ 清洗后挤干水分
✨ 避免暴晒和高温

👁️ 睫毛工具

睫毛夹、睫毛刷的使用技巧

睫毛夹

夹翘睫毛，让眼睛更有神采，为后续刷睫毛膏做准备。

✨ 眼睛向下看时夹翘
✨ 分三段夹：根部、中部、尖端
✨ 每次停留3-5秒
✨ 定期更换胶垫
✨ 用酒精棉片擦拭消毒
✨ 避免弹簧生锈

睫毛刷/睫毛膏

涂抹睫毛膏，增长加密睫毛，让睫毛更卷翘浓密。

✨ 先夹翘再刷睫毛膏
✨ 从根部Z字形向上刷
✨ 下睫毛竖刷更自然
✨ 开封后3个月内用完
✨ 不要反复抽插管身
✨ 避免接触水分

✏️ 眉部工具

眉笔、眉刷、修眉刀的使用指南

眉笔&眉刷

勾勒眉形，填充眉毛空隙，眉刷晕染让眉毛更自然。

✨ 选择接近发色的颜色
✨ 用短线条模拟毛流
✨ 眉刷晕染更自然
✨ 定期削尖保持锋利
✨ 眉刷定期清洗
✨ 避免笔芯断裂

修眉刀

修整眉形，去除杂毛，打造干净整洁的眉部轮廓。

✨ 绷紧皮肤45度角刮除
✨ 顺着毛发生长方向
✨ 少量多次避免刮伤
✨ 刀片变钝及时更换
✨ 使用后擦拭干净
✨ 放置在干燥处
